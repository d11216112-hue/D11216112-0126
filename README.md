## 英文單字學習大冒險 (English Word Learning Adventure)

An interactive word learning game that combines collection and dodging mechanics to turn word memorization into a real-time challenge!

### Features

🎮 **Complex Gameplay**
- Combines "collection" and "dodging" mechanics
- Real-time challenges that enhance memory retention

🗺️ **Map Exploration**
- Grid-based map filled with obstacles
- Navigate your character through challenging terrain

🔤 **Sequential Letter Collection**
- Collect letters in the correct spelling order
- Wrong letter = game over!
- Example: For "APPLE", collecting "P" first means failure

👻 **NPC Chase Mechanism**
- NPCs continuously pursue the player
- Adds tension and forces quick decision-making
- Practice spelling under pressure!

⏱️ **Time Challenge**
- Complete the word before time runs out
- High-frequency switching between movement and memory
- Improves focus and learning effectiveness

### How to Play

1. Open `index.html` in a web browser
2. Click "Start Game"
3. Use **Arrow Keys** or **WASD** to move your character
4. Collect letters in the correct order to spell the target word
5. Avoid NPCs (red squares with ghost emoji)
6. Complete the word before time runs out!

### Game Elements

- 🟦 **Player (P)**: Your character
- 🟥 **NPCs (👻)**: Enemy chasers
- 🟨 **Letters**: Collect in order
- ⬛ **Obstacles**: Block movement
- ⏱️ **Timer**: 60 seconds per round

### Scoring

- +100 points per correct letter
- +10 points per second remaining (bonus)

### Technologies Used

- HTML5 Canvas
- JavaScript (Vanilla)
- CSS3
